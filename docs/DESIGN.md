# (주)티앤테크 스마트워크 디자인

직원이 일정과 보고서에 바로 들어가는 포털과 팀 업무 캘린더다. 회사 표기는 요청에 포함된 값을 사용한다. 프로필과 접속 상태는 실제 로그인 세션을 표시한다. 와이어프레임 원본은 [design](design/)과 [업무관리캘린더](업무관리캘린더/) 폴더에 있다.

## 컬러와 컴포넌트

| 토큰 | 값과 쓰임 |
|---|---|
| Primary | `#1d4ed8`, 호버 `#1e40af`. 주요 버튼·선택된 보기·사이드바 활성 메뉴 |
| Surface / Canvas | 카드 `#ffffff`, 배경 `#f8f9ff`, 보조 배경 `#f8fafc` |
| 텍스트 | 제목 `#0f172a`, 본문 `#475569`, 입력 힌트 `#94a3b8` |
| 카드 `.sw-card` | 흰 배경, 테두리 `1px #f1f5f9`, 둥글기 16px, 옅은 그림자 |
| 사이드바 | `#0f172a`, 데스크톱 240px. 맨 위에 팀 공간·개인 공간 전환 |
| 탑바 | 흰색, 데스크톱 64px. 경로 표시(팀 이름 > 스케줄 관리)·검색·알림·프로필 |

업무 구분은 팀 유형마다 다르다. 배지는 `.sw-badge-{구분}` 클래스(배경·테두리·글자)와 점 색으로 구분한다.

| 팀 유형 | 구분 (점 색) |
|---|---|
| 영업형 (기술영업 1·2팀, 서울지사) | 견적 `#2563eb` · 업무협의 `#9333ea` · 납품 `#059669` · 기타 `#64748b` |
| 개발형 (솔루션개발 1·2팀, 기업부설연구소) | 개발 `#4f46e5` · 테스트 `#d97706` · 현장지원 `#0d9488` · 회의 `#9333ea` · 기타 |
| 지원형 (경영지원팀) | 구매 `#ea580c` · 결재 `#db2777` · 인사 `#0891b2` · 회계 `#65a30d` · 기타 |
| 기한 초과 | 연한 로즈 배경 `#fff1f2`, 긴급 표시는 `#f43f5e` 바탕의 흰 글자 D+일수 |

토큰과 공통 스타일은 [Smartwork.css](../frontend/src/pages/Smartwork.css), 배지는 [SharedBadges.tsx](../frontend/src/components/SharedBadges.tsx)에 있다. 스타일은 일반 CSS로 작성하며 색상 토큰은 `:root`의 `--sw-*` 변수다. Lucide 아이콘을 메뉴·업무 액션에 사용한다.

## 화면과 이동

| 화면 | 구성 |
|---|---|
| 포털 `/` | 글로벌 헤더, 직원 인사, 캘린더·워크스페이스 진입, 넓은 바로가기 카드 3개. 콘텐츠 최대 폭 1360px, 푸터 없음 |
| 워크스페이스 `/#workspaces` | 역할·직급 표시와 "접속할 워크스페이스를 선택하세요". 내 팀 카드(팀 리더·오늘 팀 업무·이번 주 예정·참여 팀원)와 개인 공간 카드(비공개), 팀장·관리자의 새 팀원 초대(제자리에서 열림), 구성원 목록(직급·관리자 표시), 작동 방식 안내, 초대 수락 대기와 재발송. 관리자·대표·본부장에게는 전체 팀 현황(팀별 유형·근무지·팀장·인원·오늘·지연, 보기 / 팀장 미지정이면 관리자에게 팀장 초대) |
| 캘린더 `/#team-calendar` | KPI, 월·주·일 캘린더, 오늘 업무·알림·기한 초과 위젯. 영업형은 "영업 캘린더", 다른 유형은 "업무 캘린더". 담당자 필터와 상세 검색(기간·업체·구분·상태). 관리자는 조회할 팀 선택과 읽기 전용 표시 |
| 업무 패널 | 새 업무 버튼과 일정 클릭에서 열린다. 1280px 이상에서는 캘린더 옆 오른쪽 고정 패널(화면을 덮지 않음), 좁은 화면에서는 덮는 패널이다. 팀 유형별 구분, 업체(영업형)·관련 업체(그 외), 시작·종료일, 시간, 알림(90일·30일·7일·3일·1일 전·당일)과 반복, 비고. 기존 업무는 상태 변경과 삭제를 제공한다 |
| 개인 공간 `/#personal-calendar` | 같은 캘린더 화면, 본인만 보는 업무. 담당자 필터·회의·보고서 메뉴 없음 |
| 업체 관리 `/#smart-clients` | 영업형 팀에만 보인다. 업체 목록, 업무 태그, 상세와 이력 |
| 회의·보고서 `/#team-reports` | 일일·주간회의와 주간 업무보고. 회의 기간의 팀 업무 체크리스트, 초안과 상신, 팀장 결재 |
| 설정 `/#team-settings` | 관리자는 조직 관리(팀 목록·수정·추가, 초대, 사용자 팀 이동·팀장 권한·직급·관리자 권한), 팀장은 팀원 초대와 초대 대기 목록, 팀원은 안내 |
| 다른 팀 조회 | 관리자·대표·본부장이 전체 팀 현황이나 사이드바 "팀 공간 선택"에서 다른 팀을 고르면 노란 읽기 전용 표시와 "내 팀으로 돌아가기"가 나오고, 등록·수정·결재 버튼이 사라진다. 상단 경로는 "팀 이름 (조회)" |

데스크톱 월간 캘린더는 해당 월에 필요한 5~6주를 표시한다. 1050px 이하에서는 좌측 메뉴를 열고 닫고 경로 표시를 숨긴다. 폼과 상세는 키보드로 열고 닫을 수 있는 HTML 다이얼로그를 사용한다(고정 패널에서도 Esc로 닫는다).

## 데이터와 연동 범위

- 캘린더, KPI, 하단 위젯, 업체 이력, 워크스페이스 통계는 같은 SQL Server 팀 업무를 읽는다. KPI는 `/api/team/dashboard`와 같은 기준이다. 메뉴를 옮기거나 화면에 돌아올 때, 1분마다 다시 읽는다.
- 서울 날짜를 기준으로 시작일에서 알림 시점을 계산한다. 반복 설정은 그 시점부터 마감일까지 매일 또는 매주 알림 목록에 반영된다. 알림은 화면 표시만 하고 외부로 발송하지 않는다.
- 보고서의 체크리스트는 해당 기간의 실제 팀 업무이며, 초안·상신·팀장 결재를 저장한다.
- 외부 푸시·메일·카카오, 기업 SSO, ERP와 독립 업체 마스터는 연결하지 않았다.
