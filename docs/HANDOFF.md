## 사용자 의도와 결정

1. 여유가 있는 날에는 일기, 바쁜 날에는 짧은 메모로 기록한다. 일기 전용 서비스로 좁히지 않는다.
2. 미래 일정·약속을 미리 등록하고 캘린더와 다가오는 일정에서 확인한다.
3. AI 기억 검색은 일기·메모를 함께 검색하고 답변에 원문 출처를 제공한다.
4. AI 약속 준비는 이미 등록한 일정과 관련된 과거 기록·준비사항·빠진 정보를 정리한다.
5. 자연어 일정 등록보다 **이미 잡은 약속을 준비하도록 돕는 기능**을 MVP에 넣는다.
6. 일정 준비는 버튼을 눌러 실행한다. 자동 알림은 범위 밖이다.
7. 주말을 빼고 평일 10일, 매일 8시간, 총 80시간으로 계획한다.
8. 산출물 전부를 먼저 완성할 필요는 없다. 최소 설계 후 기능별 구현을 진행한다.

## 현재 연결 구조와 알려진 한계

- 현재 프롬프트 경로: React → Spring Boot → FastAPI → Ollama → 응답 표시.
- 프롬프트·응답은 MySQL이나 Qdrant에 저장되지 않는다. 서비스의 기록 저장 기능 자체가 없다.
- Qdrant 실제 호출은 scripts/verify-ai-environment.py에만 있다. ai/main.py에는 업무용 Qdrant 호출이 없다. Compose 환경변수 추가만으로 호출이 구현된 것은 아니다.
- ai/main.py는 /api/generate를 사용한다. 한국어 system 지시를 추가했으나 영어 질문에 영어로 답한 사례가 있다. 한국어 질문에는 한국어 응답을 확인했다.
- /api/chat 변경은 제안만 했다. 사용자가 **변경하지 말고 먼저 테스트하겠다**고 했으므로 임의 전환하지 않는다. 모델 자체만의 문제로 확정하지 않는다.
- 프론트는 바인드 마운트와 기존 Vite polling으로 저장 시 반영한다. AI 소스는 이미지 복사 방식이므로 수정 시 docker compose up -d --build ai로 반영한다.
