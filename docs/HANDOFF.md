## 사용자 의도와 결정

1. 여유가 있는 날에는 일기, 바쁜 날에는 짧은 메모로 기록한다. 일기 전용 서비스로 좁히지 않는다.
2. 미래 일정·약속을 미리 등록하고 캘린더와 다가오는 일정에서 확인한다.
3. AI 기억 검색은 일기·메모를 함께 검색하고 답변에 원문 출처를 제공한다.
4. AI 약속 준비는 이미 등록한 일정과 관련된 과거 기록·준비사항·빠진 정보를 정리한다.
5. 자연어 일정 등록보다 **이미 잡은 약속을 준비하도록 돕는 기능**을 MVP에 넣는다.
6. 일정 준비는 버튼을 눌러 실행한다. 자동 알림은 범위 밖이다.
7. 주말을 빼고 평일 10일, 매일 8시간, 총 80시간으로 계획한다.
8. 산출물 전부를 먼저 완성할 필요는 없다. 최소 설계 후 기능별 구현을 진행한다.

- 일기·메모·일정 통합 캘린더

- AI 약속 준비·출처
- 장애·근거 부족 처리 및 데이터 유지 검증

### 1일차 종료 후 사용자 협의

- 1일차는 0단계까지 마무리했으며 1단계 최소 설계는 아직 남았다.
- 회사에서 2주 납기를 요구한다. 학습을 위해 모든 코드를 직접 작성하는 방식으로 전환하지 않고 AI 구현 지원과 사용자 이해·검증을 병행한다.
- 사용자는 AI가 의도를 임의 해석한 설계로 진행하는 것을 어려워한다. 다음 기능은 입력 위치·필수값·저장 후 동작 등 사용 흐름을 먼저 맞추고 최소 설계→작은 구현→사용 확인→문서 갱신 순으로 진행한다.
- 화면 배치 등은 구현하며 조정하되 데이터 의미·삭제·필수값은 먼저 확인한다. 납기 내 수정과 후속 아이디어를 구분한다.
- 다음 작업일의 우선 목표는 빠른 메모 저장·조회다. 먼저 환경을 짧게 확인하고 메모 동작을 사용자와 맞춘다. 가능하면 수정·삭제까지 연결한다.

최초 요청은 문서 저장이었고 이후 사용자가 0단계 착수를 요청했다. 현재 0단계까지 검증 완료했으며 업무 기능 개발은 수행하지 않았다.
